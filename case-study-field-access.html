CASE 01 / FIELD ACCESS

삼성물산
현장 출입 앱

현장 근무자가 제한된 모바일 환경에서도 빠르고 명확하게 본인을 인증하고 출입할 수 있도록 NFC·QR 흐름을 제품 화면으로 구현했습니다.

기간2026.03 — 2026.07
형태iOS · Android 앱
범위모바일 프론트엔드

공개 범위 안내. 보안 정책에 따라 현장명, 내부 시스템명, 실제 화면, 인증 규칙과 운영 수치는 공개하지 않고 역할과 문제 해결 방식 중심으로 정리했습니다.

01 / 문제

한 번의 실패가 현장 대기로 이어지는 인증 경험

출입 과정은 짧아 보여도 권한, 네트워크, 단말 상태, 태그 인식 여부에 따라 여러 예외가 발생합니다. 사용자가 실패 원인을 이해하지 못하면 재시도와 현장 지원 요청이 늘어나는 구조였습니다.

02 / 내 역할

정책과 네이티브 기능 사이를 사용자 흐름으로 연결

모바일 프론트엔드 개발자로 참여해 출입 인증의 정상·실패·재시도 상태를 화면 단위로 구조화하고, NFC와 QR 기능을 iOS·Android 앱 흐름에 연결했습니다.

  • 흐름 설계: 권한 확인부터 인증 완료까지 상태와 사용자 피드백 정리
  • 기능 구현: NFC 태그 및 QR 스캔 결과를 앱 상태와 화면에 연결
  • 협업: 기획·백엔드·QA와 플랫폼별 예외 조건 및 재현 기준 조율

03 / 핵심 구현

정상 경로보다 실패 후의 다음 행동을 먼저 보이게

  • 명시적인 인증 상태: 대기·인식·검증·완료·실패를 분리해 중복 요청과 모호한 로딩을 줄였습니다.
  • 플랫폼 예외 처리: 권한 거부, 기능 비활성화, 인식 중단 같은 상황마다 설정 이동 또는 재시도 경로를 제공했습니다.
  • 이중 인증 채널: 단말과 현장 조건에 맞춰 NFC와 QR을 일관된 피드백 체계 안에서 사용할 수 있게 구성했습니다.

04 / 결과

현장용 앱이 요구하는 예측 가능한 인증 흐름을 완성

NFC·QR 기반 출입 기능을 양대 모바일 플랫폼에 구현하고, 인증 실패 시 사용자가 스스로 다음 행동을 선택할 수 있는 화면 흐름을 마련했습니다.
