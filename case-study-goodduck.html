CASE 04 / PRODUCT

굿덕
팬 커뮤니티

팬의 게시물·음원 감상·실시간 대화를 하나의 모바일 제품으로 연결하며, 공동창업자로서 제품 우선순위와 React Native 구현을 함께 책임졌습니다.

기간2020.12 — 2021.08
형태iOS · Android 앱
범위공동창업 · PM · 개발

공개 범위 안내. 사용자 정보, 제휴·사업 조건, 서비스 운영 지표와 내부 의사결정 자료는 공개하지 않고 제품 개발 경험과 기능 범위만 소개합니다.

01 / 문제

흩어진 팬 활동을 하나의 경험으로 연결하기

팬은 커뮤니티에서 소통하고, 별도의 서비스에서 음악을 듣고, 실시간 대화를 위해 또 다른 채널로 이동해야 했습니다. 작은 팀이 이 다양한 경험을 실제 앱으로 만들려면 기능의 연결성과 개발 우선순위를 함께 다뤄야 했습니다.

02 / 내 역할

무엇을 만들지와 어떻게 만들지를 함께 책임

공동창업자이자 개발자로서 제품 요구사항과 릴리스 범위를 정리하고, React Native 앱의 주요 기능을 구현하며 서비스 출시 과정에 참여했습니다.

  • 제품 기획: 핵심 사용 시나리오와 기능 우선순위, 릴리스 범위 결정
  • 앱 개발: 커뮤니티·미디어 재생·실시간 음성 기능의 화면과 상태 구현
  • 제품 운영: 사용자 피드백과 개발 비용을 함께 고려해 개선 순서 조정

03 / 핵심 구현

서로 다른 성격의 기능을 하나의 앱 상태로 연결

  • 커뮤니티: 콘텐츠 목록과 상세, 작성과 반응의 기본 흐름을 모바일 인터랙션에 맞게 구성했습니다.
  • 음원 재생: 화면을 이동해도 재생 맥락을 유지하도록 플레이어 상태와 UI를 연결했습니다.
  • 라이브 음성채팅: 방 참여·이탈과 참여자 상태가 실시간으로 달라지는 경험을 화면 피드백으로 구현했습니다.

04 / 결과

아이디어를 사용가능한 모바일 제품으로 전환

커뮤니티, 음원 재생, 라이브 음성채팅을 포함한 모바일 제품을 구현하며 기획·개발·운영 의사결정을 제품 전체 관점에서 경험했습니다.
